    Template syntax

    Building blocks that do more than a straight swap.

    {{#var}}…{{/var}}
    Conditional block. Kept only when var has content; when it's empty the whole block — labels and all — is removed. The name must match on both ends.
    {{random:a,b,c}}
    Picks one of the comma-separated options at random each time the prompt is built.

    Empty or unknown variables resolve to nothing. Tap the eye icon above to preview the assembled prompt; the ? icon has worked examples.

      Behavior

      How large the summary may grow and how much history each update folds in.

      The summary is capped at this percentage of the Max Context Tokens budget. Pinned lines count inside this budget. Counts are estimates marked with ≈.

      When history first falls outside the context window, Cozy folds exactly this many of the oldest messages into the summary and drops them from the raw transcript. User and character messages each count as one. A larger batch means fewer, better-compressed updates, but a bigger drop in verbatim history each time.

      When the summary nears its size cap, Cozy merges this many neighbouring story lines per request to shrink it. Smaller batches lose less detail but need more requests. Pinned lines are never sent and never merged.

        Prompt syntax

        You usually don't need to touch this. The default template already builds a solid prompt for every character. Edit it only if you want to change how the prompt is put together — reorder sections, rename labels, drop one, or add your own instructions.

        The big picture

        This box holds a template: a draft with blanks in it. Each time you send a message, Cozy fills the blanks with the current character and persona, then sends the finished text to the model.

        It has two tabs, and each is its own template:

        • System goes in first, before the chat — it sets the scene and the rules.
        • User shapes the final user turn. Add {{user_message}} and the template wraps your latest message, so you can place lore, the author's note, or a reminder before or after it. Leave {{user_message}} out and it's simply appended after your message — a last note to the model right before it replies.

        Three kinds of things can go in a template: variables, optional sections, and a random pick.

        1. Variables — {{name}}

        A variable is a blank. Write {{char}} and it becomes the character's name; {{description}} becomes their description, and so on.

        You are {{char}}, talking with {{user}}.
{{description}}

        A blank with nothing to fill it just disappears. The full list is in the Variables panel beside the editor.

        2. Optional sections — {{#name}}…{{/name}}

        Say you want a [Scenario] heading, but only when the character actually has a scenario. Wrap that part in a matching pair — {{#name}} to open, {{/name}} to close — and it becomes optional.

        The rule: if name is empty, everything between the tags is removed — heading, punctuation, all of it. If name has content, the tags disappear and what's inside stays.

        {{#scenario}}[Scenario]
{{scenario}}{{/scenario}}

        With a scenario set, you get the heading and the text. With no scenario, the whole block vanishes — no empty [Scenario] heading left sitting there.

        • The name must match on both ends. {{#scenario}}…{{/scenario}} works; a typo like {{/scneario}} doesn't, and the raw tag shows up in the output.
        • "Empty" means blank, missing, or only spaces.

        3. Random pick — {{random:a,b,c}}

        Picks one of the comma-separated options each time the prompt is built.

        The weather is {{random:sunny,rainy,foggy,stormy}}.

        Blanks that come from the card

        Two variables are filled by the character card itself: {{system_prompt}} and {{post_history_instructions}}. Whatever the card puts there lands wherever you place the blank. Take the blank out and the card's text is ignored.

        Check your work

        • Tap the eye icon to preview exactly what will be sent for the current character and persona.
        • Made a typo in a tag? The preview is where you'll catch a leftover {{…}} that never got filled in.
        • You can save several templates and switch between them with the dropdown.

        Sampler reference

        Samplers shape how the model picks its next word. The defaults are sensible — only tweak these if you want to change the feel of the output. Settings marked ADV are niche or experimental.

        Core samplers

        Temperature
        How "wild" the writing is. Low (0.5) = safe and predictable. High (1.3+) = creative but risks nonsense. Most models like 0.7–1.0.
        Dynamic Temp ADV
        Lets temperature flex up or down on the fly based on how confident the model is. Range sets how far it can swing; Exponent shapes the curve. Off when range is 0.
        Top-P (nucleus)
        Only consider the smallest set of words whose combined probability adds up to this fraction. 1.0 = no filtering; 0.9 = drop the long tail of unlikely words. Lower values = safer.
        Top-K
        Only consider this many top candidates each step. 0 = unlimited. 40 is a common middle ground; 1 = always pick the single most-likely word (deterministic).
        Min-P
        Drop any word whose probability is less than this fraction of the top word's. Modern alternative to Top-P that adapts better to the model's confidence. 0.05–0.1 is typical.
        Rep. Penalty
        Discourages the model from repeating tokens it has recently used. 1.0 = off; 1.1–1.15 nudges it to use fresh words. Last N = how far back to look.

        Advanced samplers ADV

        Typical-P
        Picks tokens whose surprisal is close to the average — keeps writing "typical" rather than chasing peaks. 1.0 = off. Try 0.9 for steadier prose.
        Top-N Sigma
        Filters tokens by their distance from the mean (in standard deviations) of the model's logit scores. -1 = off. Newer alternative to Top-P/Min-P.
        Presence Penalty
        Flat penalty applied once a token has appeared at all. Pushes the model toward new vocabulary. 0 = off.
        Frequency Penalty
        Penalty that grows with how often a token has appeared. Stronger anti-repetition than Presence. 0 = off.
        DRY (Don't Repeat Yourself)
        Penalises the model for echoing recent multi-word phrases verbatim. Good for fighting "looping" replies. Multiplier = strength; Base = exponent; Allowed length = ignore phrases shorter than this.
        Mirostat
        Adaptive controller that targets a specific surprisal level (perplexity) instead of using fixed Top-P/Top-K. Tau = target surprisal; Eta = how fast it adapts. Modes: 0=off, 1=v1, 2=v2.
        XTC (Exclude Top Choices)
        With some probability, throws away the most likely tokens to force less obvious choices — adds creative spark. Probability = how often it triggers; Threshold = how confident those top picks must be before XTC kicks in.
        Seed
        Fixes the random number generator so the same prompt produces the same reply. -1 = random each time. Use a fixed seed when comparing settings.

        Different backends support different samplers — anything your engine doesn't recognise is silently ignored. When in doubt, leave the advanced ones off.
